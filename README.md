# Flake Chicken

“언제 한 번 밥 먹자”를 위한 Android·웹 약속 관리 앱.

- 약속 생성·수정·삭제와 초대 코드로 참여
- 이름·출발 주소 각 3개 저장, 환경설정 자동 저장
- 행정안전부 도로명주소 검색과 약속 시간에 맞춘 대중교통 경로·이동시간
- 비공개 파토 선택: 2명 이상 참여한 약속에서 전원 선택 시 취소 확정·시스템 알림
- GMG 모드로 새 약속 생성·참여 시 파토 자동 선택
- 파토난 약속을 처음 확인할 때 한 번만 파티클 표시
- 파토 없이 시간이 지난 약속은 금빛 표시, 명예의 전당에 보관
