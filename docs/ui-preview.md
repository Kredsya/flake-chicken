# UI 미리보기

현재 구현은 `design/`의 디자인 시안을 바탕으로 만든 Flutter Android/웹 UI입니다.
앱의 데이터 처리는 기기 안에서만 이루어지며 서버 API를 호출하지 않습니다.

## 확인할 수 있는 화면

- 약속 목록: 경로 썸네일, 작은 날짜·시간, 장소, 이동시간, 참여인원.
- 카드 동작: 카드를 누르거나 왼쪽으로 밀면 수정과 파토 토글 표시. 수정은 작성자에게만 표시.
- 파토 상태: 샘플 `한강 산책` 카드의 지도 위 빨간 `파 토` 도장. 확정된 카드는 수정·토글 불가.
- 오른쪽 아래 `+` 메뉴: 새 약속과 코드로 참여.
- 약속 생성·수정: 이름, 날짜·시간, 장소 입력 및 필수 항목 검증. 수정 화면에서 초대 코드 복사 가능.
- 코드 참여: `F7K2 M9Q4`로 샘플 약속을 확인하고 이름과 출발 주소를 각각 선택해 참여.
- 프로필: 이름 3칸, 출발 주소 3칸을 독립적으로 편집. 하나 이상의 이름과 주소가 필요.
- GMG 모드: 저장 후 새로 만들거나 참여하는 약속에서 본인의 파토 토글을 미리 선택.

약속마다 생성·참여 당시의 이름과 출발 주소를 보관합니다. 이후 프로필이나 GMG 모드를 바꾸어도
이미 있는 약속의 선택값은 바뀌지 않습니다. 약속과 설정은 앱·브라우저를 다시 실행해도 유지됩니다.

## 샘플 범위

지도는 앱에서 그리는 경로 예시이며 실제 Google Maps 데이터가 아닙니다.
38분·52분·31분은 샘플 이동시간입니다. 새 약속은 이동시간을 `—`로 표시하고,
기존 약속의 장소나 시간을 바꾸어도 샘플 시간을 그대로 사용하지 않습니다.

초대 조회는 위 샘플 코드만 지원합니다. 실제 친구의 다른 기기와 약속·선택을 주고받지는 않습니다.
이미 참여한 코드는 중복 참여할 수 없습니다. 전원 합의에 따른 취소 판정과 Android 시스템 알림은
서버 연동 단계에서 연결하며, 현재 앱 안에는 알림 다이얼로그나 알림 배너가 없습니다.

## 실행과 검증

```bash
flutter pub get
flutter run -d <기기 ID>

# 로컬 웹 미리보기
flutter run -d web-server --web-hostname 0.0.0.0 --web-port 8081

# 정적 검사와 동작 테스트
flutter analyze
flutter test

# 화면별 PNG 생성: build/ui-previews/
flutter test --dart-define=CAPTURE_UI=true test/widget_test.dart

# 빌드
flutter build apk --debug --target-platform android-arm64
flutter build web --release --no-web-resources-cdn
```

폰트는 앱에 포함되어 실행 중 외부 폰트 서버에 요청하지 않습니다.
Noto Sans KR의 라이선스는 `assets/fonts/OFL.txt`에 포함되어 있습니다.
